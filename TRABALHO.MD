Desenvolvimento
O Bloco
B
do Centro Universitário do Espírito Santo possui diversas
dependências, como salas de aula, corredores, laboratórios, banheiros e
espaços administrativos. Seu desafio será idealizar e criar um banco de dados
em MySQL
capaz de armazenar informações relevantes sobre esse bloco.
Cada grupo deverá:
1. Definir
a
abstração
dos dados
a serem representados.
o Exemplos de dados possíveis:
▪ Salas de aula (número, capacidade, recursos disponíveis);
▪ Estrutura das salas (cadeiras, quadro, projetor,
climatização);
▪ Corredores (localização, ligação entre salas);
▪ Banheiros (quantidade de cabines, acessibilidade,
localização);
▪ Laboratórios (área, computadores, softwares instalados).
2. Modelar o banco de dados de forma clara e organizada.
o Representar tabelas, chaves primárias e relacionamentos;
o Utilizar chaves estrangeiras quando necessário.
3. Criar o script SQL para a construção do banco de dados.
o Criar no mínimo 5 tabelas;
o Garantir integridade referencial (relacionamentos bem definidos).
4. Documentar o processo no Notion, incluindo:
o Título do projeto;
o Breve introdução (qual a ideia do banco e quais dados serão
armazenados);
o Diagrama/explicação da modelagem;
o Script SQL final.
Critérios de Avaliação
• Clareza e organização da abstração de dados (2 pontos)
• Modelagem coerente e bem estruturada (3 pontos)
• Uso correto de chaves primárias e estrangeiras (1 pontos)
• Documentação clara no Notion (4 pontos)
Total: 10 pontos
Observação: Não existe uma única modelagem correta. A criatividade do
grupo será valorizada, desde que atenda aos critérios de coerência, integridade
e organização.
